# Zasady współpracy - przewodnik po ZOO Online
Dziękujemy za zainteresowanie projektem ZOO Online. Poniżej znajdziesz kilka wskazówek dotyczących współpracy.

## Dodawanie nowych gałęzi
Każda nowa zmiana powinna być na nowym branchu / nowej gałęzi. Nie należy wprowadzać zmian bezpośrednio na gałezi main.
Nazwy gałęzi:
- `małpa-paulina`
- `zebra-jan`

## Commitowanie
Komunikaty commitów powinny być krótkie i jasno opisywać wprowadzone zmiany.

Przykłady:

- Dodanie małpy do strony
- Aktualizacja README
- Dodanie zdjęcia zebry
- Poprawa opisu zwierzęcia

## Komunikacja
Wszelkie uwagi, propozycje zmian oraz zgłaszanie problemów powinny odbywać się za pomocą GitHub Issues lub komentarzy do Pull Requestów.
