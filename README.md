# ZOO Online

### Opis projektu
ZOO Online to projekt strony internetowej prezentującej wybrane gatunki zwierząt. Celem projektu jest przedstawienie podstawowych informacji o zwierzętach, ich wyglądzie, środowisku życia oraz ciekawostek na ich temat. Strona zawiera zdjęcia zwierząt oraz krótkie opisy, dzięki którym użytkownik może poznać wybrane gatunki.
